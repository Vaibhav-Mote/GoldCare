1. Executive Summary & Abstract

The jewellery repair industry in India and worldwide relies predominantly on unorganized, paper-based workflows. Customers face significant friction points including lack of transparent pricing, absence of digital repair progress tracking, insecure cash advances, and difficulty discovering verified artisanal goldsmiths.

GoldCare is an end-to-end, single-page application (SPA) created to digitize and elevate the jewellery repair ecosystem. Built with a luxurious aesthetic inspired by high-end jewellery houses (gold, cream, and deep espresso tones), GoldCare provides customers with instant access to catalogued repair services, verified local workshops, an interactive 3-step repair booking engine, a real-time scannable UPI QR code payment gateway, and milestone tracking.

Simultaneously, GoldCare equips shop owners and platform administrators with a dedicated, protected management back-office to oversee partner shops, modify repair statuses, maintain customer records, export CSV business analytics, and track payments without requiring any external server infrastructure.

Architecture Philosophy: 100% Serverless & Zero-Backend
The entire application runs as a high-performance static web application hosted freely on GitHub Pages. All state mutations, shop profiles, repair bookings, and administrative settings persist reliably in the browser's LocalStorage API, making it lightweight, zero-maintenance, and cost-free to operate.

4. Detailed Module Breakdown

4.1. The 3-Step Interactive Repair Booking Engine

The booking module (src/pages/Booking.jsx) allows customers to schedule their repairs seamlessly. The form includes strict client-side validation for:

  • Customer Info: Full name, 10-digit Indian mobile number validation, and email.
  • Jewellery Details: Selection from 11 jewellery classes (Gold Ring, Necklace, Bangles, Diamond Solitaire, etc.), repair category, and photo upload (max 2MB with live canvas preview).
  • Artisan Shop & Appointment: Direct assignment to verified local partner workshops, appointment date restrictions (cannot select past dates), and preferred time slot selection.

4.2. Real UPI QR Code & Payment Escrow System

To ensure authentic business realism, GoldCare features a built-in Payment Modal (src/components/PaymentModal.jsx) that opens immediately after booking submission:

  • Dynamic UPI QR Generator: Generates real scannable QR codes complying with the official NPCI UPI specifications:
    upi://pay?pa=goldcare.jewels@okhdfcbank&pn=GoldCare%20Jewels&am=500&cu=INR&tn=GC-2026-0001
  • Custom Merchant Insignia: Features the GoldCare golden gem badge embedded directly in the center of the QR matrix, replicating merchant soundbox standees (Paytm/PhonePe).
  • 5-Minute Live Countdown Timer: Simulates gateway session timeout (04:59 counting down per second).
  • Payment Modes: Supports Advance Token (₹500), Full Estimated Amount, Debit/Credit Card, Net Banking (SBI, HDFC, ICICI, Axis), and Pay at Shop Counter.
  • Official GST Invoice: Generates a printable Tax Receipt with a unique Transaction ID (e.g. UPI/REF/984210), printable directly using window.print().

4.3. Real-Time Tracking & Pipeline Status

Customers can track any repair in real-time at #/track using their Booking ID and Mobile Number. The tracking dashboard displays:

  • Progress Pipeline: Visual 4-step stepper (Pending ➔ Confirmed ➔ In Progress ➔ Completed).
  • Artisan Notes: Live display of workshop remarks and estimated pickup times.
  • Payment Status: Shows whether the booking is paid, advance settled, or due at counter, with a built-in "Pay Online" button for unpaid bookings.

4.4. Full-Featured Admin Back-Office

Secured by ProtectedRoute.jsx, the admin portal (#/admin/login) provides workshop administrators with complete operational control:

  • Shop Management: Create, update, or deactivate repair centres across cities.
  • Booking Drawer: Slide-in detail panel to update repair stages, record payments, and append customer remarks.
  • CSV Export & Analytics: Filter reports by date and export full raw dataset to CSV via exportCSV.js.

6. Security, Validation & Business Logic

  • Client-Side Validation Engine (src/utils/validation.js): Regex-based validation for 10-digit Indian phone numbers (/^[6-9]\d{9}$/), RFC email specifications, date boundaries (preventing past date selection), and image size enforcement (≤ 2MB).
  • Authentication Guard (ProtectedRoute.jsx): Inspects localStorage.getItem('goldcare_admin_session') before rendering any admin layout. Unauthorized requests are automatically redirected to #/admin/login.
  • Zero Server Attack Surface: Because there are no backend APIs, SQL databases, or server-side scripts, the application is inherently immune to SQL injection, remote code execution, or server denial-of-service vulnerabilities.
